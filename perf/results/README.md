# Generated audit output — do not commit

Raw k6 JSON and browser measurements land here. These files are large and
regenerated by every run.

Add to `.gitignore`:

```
perf/results/
```

## Size warning

A full 1,000-VU run writes a JSON line per request sample. Expect hundreds of MB.
`report.js` reads it line by line rather than as one string for that reason.

If you want to keep the summary artefacts but not the raw data, keep
`stages.json` and `browser-*.json` and delete `load.json`.
